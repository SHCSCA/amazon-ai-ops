# 产品族只读观察：桌面会话适配

## 使用路径与边界

在现有「导入校验」页主动展开产品族只读观察，读取当前店铺、日期窗内已导入报表，逐个选择文件并输入产品族标签。预览列出 Main 核对后的文件版本、日期窗、店铺和标签；用户须再次明确确认这组文件属于该产品族，才生成只读日观察。上传、导入或输入标签本身不会构成确认。

确认仅存在于当前应用会话。它不写入数据库、不保存默认产品族、不覆盖未来文件、不改变 ASIN 原生证据、正式 AI、审批或广告执行权限。离开页面、修改选择/标签/范围、重新读取文件或切换店铺后需重新预览并确认。此功能不代替正式诊断的八类报表及采集血缘要求。

## Main 边界

Renderer 仅提交完整 StoreContext、日期窗、仓库文件 ID 和产品族标签，不能提交路径或报表字节。Main 通过当前店铺仓库取得已导入回执及批次日期，检查文件可读范围、文件大小、SHA-256 和导入版本。预览生成仅绑定当前 sender 的不透明一次性 token。确认先消费 token，再核对当前完整 StoreContext、回执和字节；过期、重放、变更或跨窗口使用均阻断。店铺切换通过已有 coordinator 的 sessionGeneration 推进，A→B→A 不恢复旧 token。

此处「用户确认」指当前桌面操作员的明确动作，不是账户身份认证、所有权证明或持久审计签名。没有新增数据库 schema 或 Grant。

## 读数含义

- 仅 campaign 层作为产品族广告观察；ad_group 是独立交叉核对；keyword 只是覆盖未知的子集，不跨层加总。
- 辅助文件只绑定版本，不被解析或纳入日对账。界面不得暗示选中的所有文件已全部核对。
- 缺失/不明确值保持未知，真实零保持零；差异照实显示，不推测原因。
- 币种、归因窗口保持未知，不从店铺默认币种推断。没有完整销售额、利润、自然销售或 ASIN 分配推导。
- 既有 helper 的 XLSX 解压内存安全仍未确立；该界面不是不受信任工作簿的沙箱。

## 验证界限

测试与浏览器预览仅使用合成文件和隔离夹具，不打开用户 profile、真实商店数据库或私人上传报表。浏览器组件截图不等于 Windows Electron、安装包、真实数据端到端验收。具体命令与结果以本次交付 README 为准；仍维持 APP_NEEDS_WORK / INTERNAL NON_READY。
